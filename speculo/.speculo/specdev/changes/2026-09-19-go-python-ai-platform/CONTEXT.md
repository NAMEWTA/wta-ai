# AI 应用服务平台

**wta-ai**：独立项目与公开仓库中的 AI Agent 平台，拥有管理控制台、开发者文档门户、Python 服务端，以及自己的构建、发布和部署资产；WTA-plus 是可通过公开网络 API 接入的外部业务系统之一。
_Avoid_: WTA 内置聊天插件、Snail AI 替代 SDK

**管理控制台（Console）**：供超管配置、开发、发布与运营 AI 应用，并创建、分发和撤销调用密钥的唯一管理前端。
_Avoid_: 开发者文档门户

**开发者文档门户（Developer Portal）**：面向外部调用者，说明如何调用已开发并发布的 Agent 服务的独立前端访问面。
_Avoid_: 管理控制台、仅供内部调试的 Swagger 页面

**运行 OpenAPI（Runtime API）**：供外部系统调用已发布 AI 应用服务并获取执行结果的机器接口合同。
_Avoid_: OpenAI 兼容接口、管理 OpenAPI

**管理 OpenAPI（Management API）**：供第三方业务系统管理平台资源、配置及应用的机器接口合同，使第三方能够实现自己的管理界面或管理集成。
_Avoid_: 运行 API Key 自动获得管理权限、只能操作 Console 私有接口

**WTA 集成方**：通过平台公开接口管理或调用 AI 服务的 WTA-plus 后端；其管理界面可以组合在 WTA-plus 中。
_Avoid_: 平台必需宿主、共享业务数据库

**平台超管**：由 wta-ai 自身认证的管理身份，集中管理资源和分发密钥；当前不建立普通用户协作或租户体系，不依赖 WTA 登录态。
_Avoid_: WTA 用户映射即登录、租户管理员、普通用户私有资源管理员

**调用密钥**：超管发放给调用者、限定可用服务与用途的凭据；持有运行密钥不等于拥有管理身份。
_Avoid_: 普通用户账号、共享超管密码、默认全平台管理 Key

**外部集成方**：通过平台公开网络协议进行管理或调用的独立系统；WTA-plus 只是其中一个可能的消费者。
_Avoid_: 平台宿主、平台内部模块

**知识库 RAG**：通过文件上传和受控 URL 接入知识，为 AI 应用提供受控上下文；首期覆盖解析/OCR与切分预览、混合检索与重排、来源引用、增量更新/重建和删除闭环。
_Avoid_: 只安装向量数据库、后续占位能力

**记忆能力**：平台首期交付的会话上下文与长期信息管理能力，短期和长期记忆均按外部业务用户区分；记忆操作受平台授权与保留策略控制。
_Avoid_: 聊天记录保留等同于自动写入长期记忆、所有调用者共享记忆

**受控连接**：由平台管理员显式登记模型、MCP 或工具目标及其出网范围的连接；内容指令不能自行创建或扩大连接权限。
_Avoid_: 任意 URL 出网、模型自主授予网络权限

**受控写工具**：会改变外部业务状态，且必须经过平台权限、审批与幂等治理的工具。
_Avoid_: 有运行 Key 即可写业务、失败后一律重试

**Skill 资源包**：平台管理的版本化指令、文件和能力声明，可引用已授权的受控工具，当前不执行任意用户代码。
_Avoid_: 自动运行脚本的插件包、任意代码执行器

**Callable（可调用体）**：平台统一描述 Agent、Graph 和 Team 的应用合同，外部调用方式不依赖其内部形态。
_Avoid_: LangGraph 类名即公开 API、三个互不兼容的应用入口

**Deployment（服务部署）**：供外部调用的已发布 AI 服务身份，关联当前可用的发布修订。
_Avoid_: Docker 容器、可变草稿

**DeploymentRevision（部署修订）**：一次不可变的服务发布版本；每个 Run 固定所使用的修订，普通发布不改写在途运行。
_Avoid_: 原地覆盖的生产配置、随运行变化的草稿

**Run（运行）**：外部调用已发布 Callable 产生的一次异步执行，受理返回 run_id，通过查询、SSE 或 Webhook 获取进展与结果。
_Avoid_: HTTP 连接、已完成的业务结果、长期会话

**门户试调**：调用者使用超管发放的受限凭据，或超管通过管理会话调用获准服务的操作，仍受授权、限额与审计约束，无需注册普通用户。
_Avoid_: 匿名演示调用、共享生产 Key

**数据保留策略**：按业务数据类别配置保存与删除规则，默认保留至主动删除；明确配置到期规则后才自动清理。
_Avoid_: 默认三十天清理、保留记录等于自动生成长期记忆

**完整内容重放**：从持久记录按原顺序读取 Run 的逐 token 内容增量及事件，保留消息与执行尝试边界；重放不会重新调用模型或工具。
_Avoid_: 只恢复最终全文、重新生成相似答案、临时流缓存

**发布质量门禁**：发布前必须通过的固定评测集、输入输出合同、授权与恢复检查；失败时不发布新修订。
_Avoid_: 仅提示评分、一次演示成功即通过

**外部业务用户标识**：可信业务后端验证自己的用户后传入的 external_user_id，与凭据授权范围和应用共同确定记忆主体；它不是平台账户或跨系统全局身份。
_Avoid_: 平台普通用户、租户 ID、仅凭字符串即验证登录

**写工具审批**：超管在管理控制台对具体业务写动作及参数作出的批准或拒绝；调用权限不代替此批准。
_Avoid_: 第三方审批系统同步、模型自行批准、一次批准任意参数

**业务记忆主体**：由已认证调用凭据的授权范围、应用与外部业务用户标识共同确定的长期记忆归属；短期记忆在该范围内再按会话区分，缺少必需标识时不回退共享记忆。
_Avoid_: 仅凭用户字符串全局检索、同一密钥下所有业务用户共享记忆

**记忆提取策略**：超管按应用配置将交互信息写入长期记忆的规则；自动提取默认关闭，开启后按规则生效，也可采用人工确认。
_Avoid_: 保留聊天记录即自动提取、未确认候选已经生效
